# Butler Tech

Maintenance ticket dashboard take-home assessment for Butler Asia.

## Requirements

- Node.js 24 (see `.node-version`)
- pnpm 12

## Workspace

- `packages/server` — Express API
- `packages/web` — Vite and React frontend

## Commands

```sh
pnpm install
pnpm dev
pnpm check
pnpm test
pnpm build
```

Run one development service with `pnpm dev:server` or `pnpm dev:web`.
